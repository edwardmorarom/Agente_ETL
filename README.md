# Agente_ETL
Agente en Python para limpieza y perfilado de datos: identifica tipos y calidad de datos por columna y fila, ejecuta un EDA automatizado y detecta valores faltantes. Arquitectura modular con métodos independientes de imputación (MICE, KNN, Hot-Deck, Cold-Deck) para tratar el missing data según el contexto de cada variable.
